# Rock Paper Scissors 

A simple Rock Paper Scissors game built with Python as part of my Python programming learning journey with Angela Yu's 100 Days of Code.

##  Project Overview

This is a command-line Rock Paper Scissors game where the user plays against the computer.

The player chooses:

- `0` for Rock
- `1` for Paper
- `2` for Scissors

The computer randomly selects its choice, and the program determines whether the player wins, loses, or draws.

##  Features

- Player input for Rock, Paper, or Scissors
- Random computer selection
- Win, lose, and draw detection
- Input validation for invalid numbers
- Clear display of both the player's and computer's choices

##  How to Run

Make sure Python is installed on your computer.

Run the program with:

```bash
python main.py
```

Depending on your Python installation, you may need:

```bash
python3 main.py
```
